# 🎯 Job Sniper CRM

A local-first application and daily quota management engine built with Python, Streamlit, and SQLite.

---

## What It Does
* **Daily Quota Enforcement:** Enforces the 23-application daily workflow (8 Long-Term Engineering + 15 Basic Non-Technical Cashflow).
* **Platform Navigator:** Shows exact search filters and direct launch links for Himalayas, Wellfound, Remotive, WWR, Jobspresso, BloggingPro, ProBlogger, and ModSquad.
* **Anti-Overqualification Guardrail:** Flags which CV to attach for every single role.
* **1-Click Pitch Generator:** Dynamically creates tailored application notes ready to copy.
* **Interview & Pipeline Tracker:** Records interview invitations, technical rounds, and offer milestones.

---

## Quick Launch
Double-click `run_job_tracker.bat` in this folder (or the root workspace).
It will automatically launch the app at:
**http://localhost:8502**
